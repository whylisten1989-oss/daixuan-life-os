## 实际浏览器检查

- 根路径按真实认证状态进入登录页或今日中枢，不再使用 `/demo`。
- 注册无需邮箱确认；登录、错误密码、密码更新和退出均已实际测试。
- 今日中枢正确区分时间轴任务、未安排具体时间的今日任务和待跟进事项。
- 任务的新建、编辑、子任务、工作/生活、循环规则、截止时间与跟进时间均已写入数据库并回显。
- 工资到账、日常支出、账户转账、预算、还款与储蓄目标会刷新首页摘要；工资到账成功后按钮立即锁定，避免重复记账。
- 饮水、睡眠、运动、步数、精力、心情、压力和体重记录会刷新健康摘要与趋势。
- 390×844 下使用独立顶部状态栏、底部导航与快速创建底部抽屉，不出现横向滚动。
- 1440×900 与 390×844 的 `documentElement.scrollWidth` 均未超过视口宽度。
- 最终 Preview 的 Vercel 构建和运行错误日志为空。

## 安全检查

- 26 张 public 表均启用 RLS。
- 客户端只使用 Supabase publishable key；仓库中不存在 service role key。
- 两个测试账户分别拥有不同个人空间，任务、财务、健康与知识记录互不可见；跨空间读取返回空结果，跨空间写入被 RLS 拒绝。
- Supabase Security Advisor 仅保留一条项目级警告：Leaked Password Protection 未启用。该项不削弱当前 RLS 或密码最小长度校验，但上线 Production 前建议在 Supabase Auth 设置中启用。

## 视觉对照结论

1. 保留概念图的窄导航、精密分隔线、时间轴中心和右侧生活信号带，不复制其素材或装饰。
2. 将概念图的资金流与身体信号语义转化为可长期使用的真实数据摘要，避免满屏发光和统一圆角卡片。
3. 中文标题、数字、辅助说明维持清晰的三级层级；桌面密度高，手机端重新排序而非压缩侧栏。
4. AI 区域明确保持“服务尚未配置”，不模拟模型回复或自动执行。
